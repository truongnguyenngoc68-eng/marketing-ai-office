# Phi Phi character standard v1

Purpose: a shared character for Trạm departments, based on the Phi Phi catalog reference supplied by the user. This is a design proposal, not an official GreenFi brand manual.

Master asset: dist/assets/phi-phi-master-v1.png. Preserve the original; create versioned siblings for variants.

Keep: turquoise flower-petal head silhouette, large circular face, dark oval eyes with small highlights, small curved smile, short round body, short limbs. Soft cartoon shading and low contrast. No mechanical robot helmet or realistic human anatomy.

Role variation: change badge, prop and clothing; keep the face, palette and body proportions. The shared character does not make every project a GreenFi project.

Current animation: browser CSS idle sway, working bob, monitor activity, processing bubble. Pause control and reduced-motion support. This is not a skeletal rig, walk cycle, or frame-by-frame character animation.

Future animation states: idle, receive brief, think, work, hand off, wait for review, success, blocked. Preserve the same silhouette between states.
