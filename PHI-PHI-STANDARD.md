# Phi Phi character standard v1

Purpose: a shared character for Trạm departments, based on the Phi Phi catalog reference supplied by the user. This is a design proposal, not an official GreenFi brand manual.

Original soft 3D master: dist/assets/phi-phi-master-v1.png. Current 2D game sprite: dist/assets/phi-phi-2d-v1.png. Preserve originals; create versioned siblings for variants.

Keep: turquoise flower-petal head silhouette, large circular face, dark oval eyes with small highlights, small curved smile, short round body, short limbs. Soft cartoon shading and low contrast. No mechanical robot helmet or realistic human anatomy.

Role variation: change badge, prop and clothing; keep the face, palette and body proportions. The shared character does not make every project a GreenFi project.

Current animation: browser CSS idle sway, working bob, monitor activity, processing bubble. Pause control and reduced-motion support. This is not a skeletal rig, walk cycle, or frame-by-frame character animation.

Future animation states: idle, receive brief, think, work, hand off, wait for review, success, blocked. Preserve the same silhouette between states.

Generated with the built-in image generation tool from the user-supplied catalog screenshot. Prompt: create a single neutral full-body Phi Phi master on transparent background, preserve turquoise round flower-petal head, dark oval eyes, small smile, short body and limbs; soft pastel cartoon shading, relaxed open greeting, no props or clothing. Catalog reference only informs character identity; all claims and layout text are excluded.

2D sprite prompt: preserve Phi Phi identity and flower head, convert to thin teal outlines, broad pastel flat colors and simple cel shading, one full-body friendly neutral greeting pose, transparent background, no props/text. Generated with the built-in image tool, not a vector conversion.

Cloud Campus environment: dist/assets/cloud-campus-v1.png. Built-in image edit of selected design 03, removing all UI, text and characters and retaining the furnished pastel isometric office. HTML supplies the live characters, names, states and click targets independently.
